JsxposedX-Mod - 关于我们
=====================================

JsxposedX-Mod 是基于 dugongzi/JsxposedX 的二次开发版本。

核心特性：
- 无需 root、无需面具、无需授权
- 仅依赖 Dhizuku 辅助权限即可完成 Xposed 模块注入
- 注入路径：/data/data/xyz.dhiyan.dhizuku/files/modules/
- 目标进程重启后自动加载模块

技术基座（全部基于开源项目）：
- JsxposedX：Xposed hook 核心
- Dhizuku：Android 辅助权限管理器
- proot：用户态 Linux 环境
- Alpine Linux：轻量根文件系统
- apktool / jadx / apksigner：APK 逆向、分析与签名
- OkHttp / AndroidX / Material：应用框架

开源仓库：https://github.com/1953187487/JsxposedX-Mod
上游项目：https://github.com/dugongzi/JsxposedX
